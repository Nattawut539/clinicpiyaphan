# ClinicCare Frontend

ส่วนติดต่อผู้ใช้ของ ClinicCare พัฒนาด้วย Next.js, React และ TypeScript

เริ่มจาก [คู่มือติดตั้งที่ root](../README.md) ซึ่งอธิบายฐานข้อมูล backend บัญชี demo และ environment ครบทั้งระบบ

เมื่อเตรียม backend แล้ว รันในโฟลเดอร์นี้:

```sh
npm ci
npm run dev
```

เปิด `http://localhost:3000/userlogin` ใช้ `npm run lint` ตรวจโค้ด และ `npm run build` สร้าง production build
